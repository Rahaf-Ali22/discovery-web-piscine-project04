
# Personal Portfolio — Project 04

## About the Project

A responsive personal portfolio website built using HTML5, CSS3, and JavaScript as part of the 42 Amman Discovery Web Piscine.

The website introduces my background, technical skills, learning projects, hobbies, and contact information.

## Technologies Used

- HTML5 — Semantic structure
- CSS3 — Styling, Flexbox, Grid, and responsive design
- JavaScript — DOM manipulation and interactive features
- Git & GitHub — Version control

## Features

- Responsive navigation bar
- About Me section with profile photo
- Skills and technologies grid
- Project showcase covering Projects 00–03
- Hobbies and interests section
- Contact form with email draft functionality
- Light and dark theme switcher
- Interactive project cards
- Responsive layouts for different screen sizes
